## Modules

### `/admin`
Administrative pages, authentication, helpers, tools, documentation, and runtime data. Root `.htaccess` denies direct access to private backend folders and configuration. Legacy `/uploads/` URLs map to `/admin/uploads/`; root IndexNow key URLs map to their files under `/admin`. Git and web-server control files remain at the repository root.

### `/api`
PHP API endpoints.

### `/admin/includes`
Shared database connection, configuration, helpers, and reusable PHP logic.

### `/admin/storage`
Runtime application storage, ignored by Git. No placeholder files are required.
`admin/includes/blog-storage.php` creates this directory with mode `0700` and opens
`blogs.sqlite` on first use, applying the existing idempotent schema and default
categories/settings. `APP_STORAGE_DIR` can override the directory. No users,
blog posts or games are seeded. Existing databases and legacy JSON migration
continue through the same bootstrap.

API caches, ticket/click archives and rate-limit files are created on demand.
Logs and update backups are generated by their respective utilities; chat files
and uploads remain in their separate directories. Schema definitions live in
`/includes`, not in runtime storage. PHP with PDO SQLite and a writable storage
parent (or configured storage directory) is required.

Run `php admin/scripts/test-fresh-storage.php` to check missing and empty storage,
schema creation, public list/settings handlers, and preservation of existing data
in an isolated source-only copy.

### `/admin/uploads`
Uploaded media and files.

### `/admin/scripts`
Maintenance utilities.

Current Python utility:

`admin/scripts/enrich-game-descriptions.py`

### `/admin/chats`
Chat-related data and logs.
